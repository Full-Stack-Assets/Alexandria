# Alexandria Library — UE 5.8 procedural greybox plugin

A self-contained Unreal Engine plugin that generates a walkable "Library of
Alexandria" greybox: a central atrium, an octagonal domed hall, six ringed
halls, and an optional underground chamber grid.

## Install
1. Copy this `AlexandriaLibrary/` folder into your project's `Plugins/`
   directory (create `Plugins/` at the project root if it doesn't exist yet).
2. Regenerate project files, then build.
3. Open **Edit > Plugins** and confirm **Alexandria Library** is enabled
   (it loads by default once present in `Plugins/`).
4. Enable **Show Engine Content** in the Content Browser's View Options so
   the `/Engine/BasicShapes/` cube and cylinder resolve. If they don't, the
   actor no-ops safely (the `if (!CubeMesh ...)` guard in `OnConstruction`).

## Use
- Drag **AlexandriaLibraryActor** into a level. Geometry builds in
  `OnConstruction`, so it appears immediately and rebuilds whenever you edit
  its Details panel.
- Tunables in Details: atrium diameter/column count, central hall
  radius/height, dome ring count, the editable **Rooms** array, and a
  **Build Underground** toggle (off by default — the "optional" complex).
- Assign **Marble** and **Stone** materials in the Materials section; leave
  them empty for plain greybox.

## What it generates
- Central atrium: circular marble floor, colonnade ring, stone fountain basin.
- Octagonal domed central hall enclosing the atrium, with the -X wall left
  open as the entrance and a stepped-disc dome.
- Six ringed halls from the concept table, each with floor, walls, a doorway
  gap facing the atrium, and optional interior column rows.
- Optional 3x3 underground stone chamber grid one level down.

## Architecture
- `AlexandriaLibrary.uplugin` — plugin descriptor; single `Runtime` module.
- `Source/AlexandriaLibrary/Public/AlexandriaLibraryModule.h` /
  `Private/AlexandriaLibraryModule.cpp` — minimal `IModuleInterface` so the
  plugin loads/unloads cleanly like any other engine or marketplace plugin.
- `Source/AlexandriaLibrary/Public/AlexandriaLibraryActor.h` /
  `Private/AlexandriaLibraryActor.cpp` — the procedural actor itself. Public
  header, private implementation, matching standard UE plugin layout.
- The actor's API macro is `ALEXANDRIALIBRARY_API`, generated by UBT from the
  module name — no manual renaming needed when dropped into a new project,
  unlike the loose-file version this plugin was assembled from.

## Notes
- Everything is unit-cube / unit-cylinder greybox — Static Mobility, meant for
  layout and walkability blockout, not final art. Swap the basic shapes for
  real meshes once the footprint feels right.
- Columns are drawn through a single `UInstancedStaticMeshComponent` so a full
  colonnade stays cheap.
- To make it walkable, drop a **Player Start** near the entrance (roughly
  world X = -60 m from the actor) and set a default pawn / Game Mode.
